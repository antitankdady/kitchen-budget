# プロジェクト仕様書 (Kitchen Budget)

## 1. アプリケーション概要
名称: Kitchen Budget
目的: シンプルな食費管理と割り勘計算機能の提供。
特徴:
- ユーザー登録不要（ローカルストレージ保存）。
- 消費税計算（8%, 10%）のワンタップ入力。
- 負担割合（%）の設定による実費計算。
- CSVファイルの出力・取り込みによる端末間のデータ受け渡し（外部サービス連携なし）。
- ダークモード対応。

## 2. 機能要件

### 2.1 支出管理
- 一覧表示: 日付順（降順）に支出を表示。
- 新規登録: 日付、金額（税抜）、カテゴリ、負担割合、メモを入力。
- 編集: 登録済みデータの修正。税税率情報（taxRate）も保持し、再編集時に二重課税を防ぐ。
- 削除: データの削除。

### 2.2 計算ロジック
- 消費税:
    - ボタン（+8%, +10%）により税抜金額から税込金額（切り捨て）を算出。
    - 排他制御：同時に適用できる税率は1つ。
    - トグル：適用中の税率ボタン再押下で税抜金額に戻る。
- 割り勘（実費）:
    - `金額 * (負担割合 / 100)` で算出（切り上げ表示）。

### 2.3 フィルタリング
- 期間: 開始日・終了日で絞り込み（デフォルト：当月1日〜末日）。
- カテゴリ: 全て、肉、魚、野菜、外食、全般。
- 合計表示: フィルタリングされた結果に基づいて「合計」と「自分の実費」を再計算して表示する。

### 2.4 データの入出力（CSV）
端末間のデータ受け渡しは、CSVファイルを手動で受け渡す方式とする（非同期。クラウド連携は行わない）。設定画面から操作する。

- 出力（エクスポート）:
    - フィルタに関係なく、全データを出力する。
    - ファイル名: `kitchen-budget_YYYYMMDD_HHmm.csv`（出力時のローカル日時）。
    - 文字コード: UTF-8（BOM付き。Excelで文字化けしないため）。改行: CRLF。
    - 1行目はヘッダ行。列順: `id,date,amount,category,ratio,taxRate,memo,createdAt,updatedAt`
    - `category` はキー（`meat` など）で出力する。
    - `taxRate`・`memo` が未設定の場合は空欄。
    - カンマ・ダブルクォート・改行を含む値はダブルクォートで囲み、内部のダブルクォートは `""` にエスケープする。
- 取り込み（インポート）:
    - ファイル選択ダイアログで `.csv` を選択する。
    - 文字コード: UTF-8（BOM有無は問わない）。UTF-8として読めない場合は Shift_JIS として読む（Excelで「CSV（コンマ区切り）」保存したファイルを想定）。
    - ヘッダ行の列名で列を特定する（列順は問わない）。`date`, `amount`, `category`, `ratio` 列は必須。その他の列は省略可。
    - 取り込み方法を選択する:
        - 追加・更新（マージ）: `id` が一致するデータは `updatedAt` が新しい方を採用する。一致しないデータは追加する。既存データは削除しない。
        - 置き換え: 既存データをすべて削除し、ファイルの内容に置き換える。
    - 実行前に確認ダイアログを表示し、実行後に結果（追加・更新・変更なし・スキップの件数）を表示する。
    - 行ごとの検証（不正な行はスキップし、行番号を結果に表示する）:
        - `date`: `YYYY-MM-DD` または `YYYY/M/D` 形式の実在する日付（`YYYY-MM-DD` に正規化して保存）。
        - `amount`: 0以上の整数。
        - `category`: キー（`meat` など）または表示名（`肉` など）。
        - `ratio`: 0〜100 の整数。
        - `taxRate`: 空欄、`0.08`、`0.1`（`0.10`）のいずれか。
    - 補完:
        - `id` が空欄の行は新規データとして新しいUUIDを付与する（手作業で作成したCSVを想定）。
        - `createdAt`・`updatedAt` が空欄または不正な場合は取り込み時刻を設定する。
        - 空行は無視する。
    - 削除の同期は行わない（マージでは、他端末で削除したデータは残る。必要な場合は置き換えを使う）。

## 3. データモデル (Expense)
| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | string | Yes | UUID |
| `date` | string | Yes | YYYY-MM-DD |
| `amount` | number | Yes | 金額（税込） |
| `category` | Category | Yes | `meat`, `fish`, `vegetable`, `eatingout`, `general` |
| `ratio` | number | Yes | 負担割合 (0-100) |
| `taxRate` | number | No | 適用された税率 (0.08 or 0.10) |
| `memo` | string | No | メモ |
| `createdAt` | string | Yes | ISO String |
| `updatedAt` | string | Yes | ISO String |

## 4. 技術スタック
- Frontend: Vue 3 (Script Setup), TypeScript
- State Management: Pinia (Persistence: LocalStorage)
- Tooling: Vite
- Infrastructure: GitHub Pages (GitHub Actions で自動デプロイ)

## 5. UI/UX
- テーマ: ダークモード自動対応（CSS変数使用）。
- レスポンシブ: モバイルフレンドリーなレイアウト。
- 画面遷移: ホーム画面のフィルタ行右端に「+」（新規登録）と「⚙」（設定）ボタンを配置する。
